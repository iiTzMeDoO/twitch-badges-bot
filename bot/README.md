# بوت بادجات — badgecollectorsxx

بوت Twitch يفحص `js/data.js` بموقعكم بشكل دوري، ولما يلقى بادج جديد صار
"متاح الآن" أو "متاح قريبًا" يكتب اسمه ورابط الموقع بالشات. أي حد يكتب
"بادجات؟" بالشات يوصله رسالة فيها كل البادجات المتاحة الآن والقريبة
بأسمائها + رابط الموقع للتفاصيل. الإعدادات تتحكم فيها بأوامر شات
(`!badgebot ...`) مقصورة على البرودكاستر/المودز.

البوت كمان يدخل تلقائياً أي قناة ضغط صاحبها زر **"أضف البوت لقناتك"**
بالموقع (يمرّ بتفويض تويتش، يسجل القناة بـ Firestore عن طريق
`api/join_start.py` و`api/join_callback.py` بالموقع، والبوت يفحص
القائمة كل بضع دقايق عن طريق `api/bot_channels.py` وينضم تلقائياً).
لما ينضم، البوت يصير **مشرف (مود)** بالقناة تلقائياً (عن طريق Helix
Add Channel Moderator API — ما يحتاج البرودكاستر يكتب `/mod` يدوياً).

> ⚠️ **ملاحظة عن "الفولو التلقائي":** تويتش شالوا من زمان (يوليو 2021)
> إمكانية أي تطبيق يخلي حساب "يتابع" (follow) قناة تانية تلقائياً
> بالنيابة عن مستخدم — ما فيه أي API رسمي لهذا الشي حالياً ولا طريقة
> مسموحة تسويه من طرف بوت. فـ زر "أضف البوت لقناتك" يسوي كل شي ممكن
> فعلياً (البوت يدخل الشات + يصير مود تلقائياً)، بس ما يقدر يخلي حساب
> البوت "يتابع" قناتكم تلقائياً.

> ℹ️ **ليش هذا مهم بالذات؟** بعض القنوات تحط الشات بوضع "متابعين فقط"
> (followers-only)، وبهالوضع أي حساب مو مود ولا برودكاستر ما يقدر يكتب
> أي رسالة — والمشكلة إن تويتش IRC ما يرجع أي خطأ واضح، الرسالة توصل
> بصمت بدون أي تنبيه. الحل الصحيح مو "الفولو" أصلاً، لأنه **المشرفين
> (المودز) دايماً مستثنون من وضع "متابعين فقط" وغيره من قيود الشات**
> (بطيء، مشتركين فقط...) — فطالما البوت صار مود فعلاً (خطوة تلقائية
> بزر "أضف البوت لقناتك")، مايهمش وضع الشات إطلاقاً. البوت كمان يتأكد
> بنفسه دورياً (عن طريق Twitch API، مو افتراضاً) إنه فعلاً مود بكل قناة
> داخلها، ولو لقى قناة هو مو مود فيها (مثلاً فشلت خطوة التمويد التلقائي
> لأي سبب) يحط تحذير بالـ console ويكتب بالشات نفسها يطلب من
> البرودكاستر يكتب `/mod badgecollectorsxx` يدوياً.

## 1) التثبيت

```bash
cd bot
npm install
```

## 2) الإعدادات

```bash
cp .env.example .env
```

افتح `.env` واملأ:
- `TWITCH_CLIENT_ID` و `TWITCH_CLIENT_SECRET` — من
  https://dev.twitch.tv/console/apps → التطبيق تبعكم → Manage.
- تأكدوا أن **OAuth Redirect URLs** بإعدادات التطبيق (dev.twitch.tv/console/apps)
  فيها بالضبط الثلاث روابط:
  - `http://localhost:3000/callback` (لتسجيل دخول حساب البوت محلياً)
  - `https://badgecollecctorsxx.vercel.app/api/bot_oauth_callback` (تسجيل دخول حساب البوت من الموقع، اختياري)
  - `https://badgecollecctorsxx.vercel.app/api/join_callback` (**مطلوب** لزر "أضف البوت لقناتك")
- على Vercel، تأكدوا هذي المتغيرات موجودة بإعدادات المشروع (Environment Variables):
  `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`, `FIREBASE_SERVICE_ACCOUNT_JSON`
  (نفس المتغيرات اللي أصلاً مستخدمة بـ admin.html وباقي api/).
- `BOT_LINK_SECRET` — سر مشترك عشوائي (مثلاً `openssl rand -hex 24`) لازم
  يكون **بنفس القيمة بالضبط** بمكانين:
  1. متغيرات بيئة الموقع بـ Vercel (`BOT_LINK_SECRET`).
  2. متغيرات بيئة البوت (`.env` محلياً أو إعدادات المنصة اللي شغّال عليها البوت).
  يستخدمه البوت عشان يثبت لـ `/api/join_callback (POST)` إن الطلب جاي منه
  هو فعلاً، مو من أي حد ثاني — مطلوب لـ"الطريقة الثانية" (زر "أضف
  البوت بكود" بالموقع، بدون تسجيل دخول بتويتش: المستخدم يوّلد كود من
  الموقع، يكتبه بشات قناة البوت `!link <code>`، والبوت يدخل شاته فوراً).
- ⚠️ **إذا كان عندكم tokens.json قديم من قبل**، لازم تمسحوه وتعاودوا
  `npm run get-token` من جديد — أضفنا صلاحية `user:read:moderated_channels`
  الجديدة (يحتاجها البوت عشان يتأكد بنفسه هل هو مود فعلاً بكل قناة، شوف
  الملاحظة فوق)، وتوكن قديم ما فيه هالصلاحية.

## 3) تسجيل دخول حساب البوت (مرة وحدة بس)

```bash
npm run get-token
```

يطبعلكم رابط، افتحوه بالمتصفح وسجّلوا دخول **بحساب badgecollectorsxx**
ووافقوا على الصلاحيات. بعدها يتحفظ `tokens.json` تلقائياً (يتجدد لوحده
بعدين، ما تحتاجوش تعاودوا هذي الخطوة إلا إذا مسحتوه أو بدلتوا الحساب).

## 4) تشغيل البوت

```bash
npm start
```

البوت يدخل القنوات المذكورة بـ `config.json` فوراً، يفحص البادجات،
وبعدها كل `checkIntervalMinutes` (افتراضي 5 دقايق). وبالتوازي، كل
`channelPollIntervalMinutes` (افتراضي 3 دقايق) يفحص `api/bot_channels`
بالموقع وينضم تلقائياً لأي قناة جديدة ربطت البوت من زر الموقع.

## أوامر التحكم بالشات

- `بادجات؟` (أو `بادجات`) — يرسل قائمة كل البادجات المتاحة الآن
  والقريبة بأسمائها + رابط الموقع (يقدر يستخدمه أي حد بالشات)
- `!badgebot status` — يعرض الإعدادات الحالية (يقدر يستخدمه أي حد)
- `!badgebot alerts on|off` — تشغيل/إيقاف تنبيهات البادج الجديد (مودز/برودكاستر)
- `!badgebot interval <دقايق>` — تغيير فترة الفحص، من 1 لـ 60 دقيقة (مودز/برودكاستر)

## ملاحظات

- `config.json` — فيه القنوات الثابتة وإعداداتها (قناتكم الرئيسية).
  القنوات اللي تنضاف من زر "أضف البوت لقناتك" بالموقع ما تنكتب هنا —
  تتحفظ بـ Firestore والبوت يجيبها ديناميكياً من `channelsApiUrl`.
- `state.json` — يتخزن فيه أوتوماتيك أي بادج/حالة سبق اتعلن، ما تحتاجوش
  تلمسوه. لو مسحتوه، البوت يعتبر كل شي "جديد" بأول فحص بدون إعلان
  (تسجيل أولي صامت) وبعدها يبدا يعلن عن أي تغيير حقيقي.
- `.env` و `tokens.json` و `state.json` ماشي للمشاركة أبداً (موجودين
  بـ `.gitignore` أصلاً) — فيهم أسرار حساب البوت.
- إذا حسابكم بغى يبان بالشات مثل بوت (اختياري بس مو ضروري)، تقدروا
  تطلبوا من Twitch تفعيل "Verified Bot" لاحقاً.
